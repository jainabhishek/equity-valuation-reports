What's in each memo

Every company folder pairs a self-contained HTML memo with a live Excel model. The model is a second implementation rather than a printout: a formula engine recalculates it and ties all 20 checks to the Python engine, including free cash flow in every forecast year.

  • memo.html — primary read: rating, variant vs consensus, Shapley price-to-value bridge, scenarios and expected value, sizing, kill criteria, dated catalysts, falsification, evidence appendix
  • model.xlsx — live model: every driver a blue input cell, one WACC definition, vintage depreciation schedule. Verified cell-for-cell against the Python engine.
  • report.html, banker_formula_workbook.xlsx — the earlier screen-grade artefacts, retained for comparison. Superseded.
  • build/ — the pipeline: SEC XBRL client, quarterly-series reconstruction, driver cases, depreciation schedule, DCF and Shapley attribution, decision layer, renderers and the verification script
