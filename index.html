What's in each report

Every company folder pairs a standalone HTML report — thesis, operating deep dive, scenario valuation, catalysts, risks, and sources — with a linked Excel workbook that fully derives the DCF from formulas, not hardcoded outputs.

  • report.html — primary read: verdict, operating metrics, base-case build, scenario table, catalysts/risks
  • banker_formula_workbook.xlsx — dashboard, scenarios, reverse DCF, sensitivities, integrity checks
  • plan.json / model_citations.json — normalized assumptions and a cell-by-cell citation ledger
